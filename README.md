# Tutorial to Run the Project

Here is a simple guide to run this project locally.

## Prerequisites

Make sure you have installed:

- **Node.js**

## Steps to Run the Project

1. **Download this project:**

   ```bash
   git clone https://github.com/Faizanriaz44553/My-Second-Portfolio.git
   ```

2. **Download the project:**

   ```bash
   git clone https://github.com/Faizanriaz44553/My-Second-Portfolio.git
   ```

3. **Install all dependencies:**

   ```bash
   npm install
   ```

   or

   ```bash
   npm install --legacy-peer-deps
   ```

4. **Run the project:**

   ```bash
   npm run dev
   ```

5. **Open in your browser:**

   Access the application in your browser using the link displayed in the terminal.

## Create a Production Build

To create a production-ready build:

1. Run the build command:

   ```bash
   npm run build
   ```

2. The build files will be generated in the `dist` folder. You can upload this folder to your hosting server.

## Notes

If you encounter any issues while running the project, make sure:

* Node.js is installed correctly.
* You are inside the correct project folder.
* All dependencies are installed without any errors.

## Firebase Configuration

To configure Firebase for this project, follow these steps:

1. **Add Firebase to the Project:**

   * Open https://console.firebase.google.com/.
   * Create a new project or use an existing one.

2. **Select Firestore Database**

   * Click **Create Database**.

3. **Go to Project Settings**

   * Click on this section: ![Screenshot 2024-12-30 214204](https://github.com/user-attachments/assets/43243cad-b414-4dd9-8793-d15c401c82fe)
   * Then copy your Firebase configuration from here: ![image](https://github.com/user-attachments/assets/6d0e158c-1ae0-40c1-8b41-9e53a1c4ccbb)

4. **Go to Rules**

   * Change the rules to `true`.

5. **Match the Collection Structure as shown below**
   ![Screenshot 2025-01-03 001341](https://github.com/user-attachments/assets/38580122-08a4-4499-a8fd-0f253652a239)
   ![Screenshot 2025-01-03 001410](https://github.com/user-attachments/assets/d563d7ad-f1ab-46ff-8185-640dcebd0363)

6. **Open the `firebase.js` and `firebase-comment.js` files**

   * Replace the `firebaseConfig` object with your own Firebase configuration.
